# Drowsiguard
An AI-powered Drowsiness Detection System to prevent accidents caused by driver fatigue.  DrowsiGuard uses real-time computer vision and AI to monitor eye movements and facial landmarks to detect signs of drowsiness. If drowsiness is detected, the system alerts the user instantly — ensuring safety on the road.
# DrowsyGuard 😴🚗  
*Prevent Drowsiness. Protect Lives.*

---

## About the Project

DrowsyGuard is an AI-powered Driver Drowsiness Detection System designed to ensure road safety by monitoring driver alertness in real-time. Our solution uses cutting-edge computer vision and deep learning models to identify signs of fatigue and instantly alert the driver — preventing potential accidents before they happen.

---

## Features 🚀

- Real-time Driver Drowsiness Detection
- Eye Blink & Yawn Detection
- Sound Alerts for Drowsiness
- Beautiful Web Interface for Interaction
- Trained Custom CNN Model for Accuracy
- Easy to Integrate in Any Vehicle System

## How It Works ⚙️

1. User opens the web interface.
2. Camera starts capturing the driver's face.
3. Flask backend processes the live feed.
4. CNN model detects:
   - Closed Eyes
   - Yawning
5. Alert sound is triggered if drowsiness is detected.
